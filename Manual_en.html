1. Create a template in Gmail

Write the email and save it as a draft. For parts that differ per recipient, use the column headers of your sheet, e.g. {{Name}}, {{Company}}. Case and spaces are ignored: {{Email Address}} = {{emailaddress}}.
Emoji (🎄🎁) in the subject, body and sender name are supported. Inline images and attachments are sent as-is.

2. List recipients in a sheet

Row 1 is the header row. Name the email column Email (or Email Address). A Mail Merge Status column is added automatically if missing.

3. Run the mail merge

Menu ▼Mail Merge▼ → Open Mail Merge. Choose the template, sheet and From address, send a test email to yourself first, then choose Run mail merge. RUN shows the number of recipients; click again to start sending.

4. Check the results

Sent rows are marked EMAIL_SENT; failed rows show ERROR: reason. Rows marked EMAIL_SENT are never sent again — clear the cell to resend. If a long list hits the time limit (about 5 minutes), click RUN again to continue where it stopped.

5. Slide image (optional)

Design the first slide of a Google Slides file with fields such as {{Name}}, then put {{SlideImage}} in the email body. Each recipient gets a personalised image card.

Language

Change the language with 🌐 at the top of the sidebar. The menu changes after reloading the spreadsheet.
