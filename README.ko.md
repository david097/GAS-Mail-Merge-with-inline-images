# GAS Mail Merge with inline images

[English](README.md) | **한국어**

Gmail 임시보관함의 초안을 템플릿으로, Google 시트에 있는 사람들에게 이름·회사 등을 넣은 개인 맞춤 메일을 보냅니다. 본문 삽입 이미지, 첨부파일, 이모지, 보내는 주소 별칭을 지원합니다. Google Apps Script로 만들었고 부가기능 설치는 필요 없습니다.

## 기능

- **Gmail 초안을 템플릿으로** — Gmail에서 메일을 쓰고 제목·본문에 `{{열 이름}}` 머지 필드를 넣습니다. `{{이름}}` 같은 한글 필드도 됩니다.
- **본문 삽입 이미지와 첨부파일**이 초안 그대로 나갑니다.
- **이모지 지원** — Gmail API로 UTF-8 MIME 메일을 직접 보내서 🎄🎁가 `��`로 깨지지 않습니다.
- **보내는 주소 별칭** — Gmail '다른 주소에서 메일 보내기'에 등록한 주소로 발송, Reply-To도 같은 주소로 설정.
- **테스트 메일** — 전체 발송 전에 나에게 먼저 1통.
- **이어서 발송** — 보낸 행은 `EMAIL_SENT`, 실패한 행은 사유를 기록하고 다음 사람은 계속 발송. 명단이 많으면 6분 제한 전에 멈추고 다시 실행하면 이어서 보냅니다.
- **슬라이드 이미지(선택)** — 슬라이드 첫 장을 사람마다 이름을 넣어 이미지로 만들어 `{{SlideImage}}` 자리에 삽입.
- **한/영 화면** — Google 계정 언어에 맞춰 자동 선택, 사이드바에서 변경 가능.

## 설치

### 방법 A — 샘플 시트 복사

1. [샘플 스프레드시트](https://bit.ly/2ZJmLwL)를 열고 **파일 → 사본 만들기**.
2. 사본을 열고 새로고침하면 **▼Mail Merge▼** 메뉴가 생깁니다.
3. 처음 실행할 때 권한 승인 창이 뜹니다. "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누르세요. 스크립트는 내 계정 안에서만 동작합니다.

### 방법 B — 직접 설치

1. Google 시트를 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. 이 저장소의 파일을 같은 이름으로 추가합니다.

   | 파일 | 종류 |
   |---|---|
   | `Code.gs`, `i18n.gs`, `Lang_en.gs`, `Lang_ko.gs` | 스크립트 |
   | `MailMerge.html`, `Manual_en.html`, `Manual_ko.html` | HTML |

3. **프로젝트 설정 → "appsscript.json" 매니페스트 파일 표시**를 켜고 내용을 [`appsscript.json`](appsscript.json)으로 바꿉니다. **Gmail API**와 **Google Slides API** 고급 서비스가 켜집니다. (또는 **서비스(+)**에서 직접 추가)
4. 스프레드시트를 새로고침합니다.

## 사용법

1. **Gmail에서 초안 작성.** 시트 머리행 이름을 머지 필드로 씁니다.

   ```
   제목: 🎄 {{이름}}님, 송년회에 초대합니다
   본문: 안녕하세요, {{회사}}의 {{이름}}님! ...
   ```

   대소문자·띄어쓰기·기호는 구분하지 않습니다: `{{Email Address}}` = `{{emailaddress}}`

2. **시트에 받는 사람 목록 작성.** 1행은 머리행이고, 이메일 열 이름은 `Email`, `Email Address`, `이메일` 중 하나로 적습니다.

   | 회사 | 이름 | 이메일 | Mail Merge Status |
   |---|---|---|---|
   | NSHC | 홍길동 | hong@example.com | |

3. **▼Mail Merge▼ → 메일머지 열기**에서 초안, 시트, 보내는 주소를 고릅니다.
4. 먼저 **테스트 메일 보내기**로 내 메일함에서 확인합니다.
5. **메일머지 실행 → RUN**. 대상 인원이 표시되고, 한 번 더 누르면 발송합니다.

### 결과

| 상태 | 의미 |
|---|---|
| `EMAIL_SENT` | 발송 완료. 다음 실행 때 건너뜁니다. 재발송하려면 이 칸을 지우세요. |
| `ERROR: …` | 실패와 사유. 고친 뒤 RUN을 다시 누르세요. |

### 슬라이드 이미지 (선택)

1. Google 슬라이드 **첫 장**에 `{{이름}}` 등을 넣어 디자인합니다.
2. 메일 본문에 `{{SlideImage}}`를 넣습니다.
3. 사이드바에서 **슬라이드 이미지 넣기**를 체크하고 슬라이드를 고릅니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| `Gmail API 서비스가 추가되지 않았습니다` | 서비스(+)에서 **Gmail API** 추가, 또는 제공된 `appsscript.json` 사용 |
| `… API has not been used in project … or it is disabled` / `API가 꺼져 있습니다` | 스크립트가 별도 Google Cloud 프로젝트에 연결된 경우입니다. 메시지의 링크를 열어 **사용(ENABLE)**을 누르세요 (Gmail API, 필요하면 Slides API). |
| `이메일 열을 찾을 수 없습니다` | 이메일 열 머리행을 `Email` 또는 `이메일`로 |
| 메일에 값이 빈칸으로 나옴 | 결과 창에 '시트에 없는 필드'가 표시됩니다. 머리행 이름과 철자를 확인하세요. |
| 하루 발송 한도 | Gmail 자체 발송 한도 적용 (Google Workspace 계정 하루 약 2,000통, 개인 Gmail 계정은 더 적음) |
| 큰 첨부파일 실패 | Gmail API 요청 크기 제한이 있습니다. 큰 파일은 드라이브 링크로 공유하세요. |

## 언어 추가하기

1. `Lang_en.gs`를 `Lang_<코드>.gs`(예: `Lang_ja.gs`)로 복사하고 `LANGS.en`을 `LANGS.ja`로 바꿉니다.
2. 값을 번역합니다. `{placeholder}`와 `{{머지 필드}}`는 그대로 둡니다. 빠진 키는 영어로 표시됩니다.
3. `Manual_en.html`을 `Manual_<코드>.html`로 복사해 번역합니다.
